# Тест-план: Автоматизация тестирования DemoQA

## 1. Введение

### 1.1 Цель

Создание фреймворка автоматизированного тестирования для сайта <https://demoqa.com/>
с использованием Playwright + Python + pytest.

### 1.2 Область тестирования

- **Elements:** TextBox, CheckBox, RadioButton, WebTables, Buttons, Links
- **Forms:** Practice Form
- **Alerts, Frame & Windows:** Alerts, Browser Windows
- **Widgets:** DatePicker, Select Menu

### 1.3 Не входит в область

- Производительность и нагрузочное тестирование
- Тестирование безопасности (кроме базовых проверок)
- Мобильное тестирование
- Book Store Application (требует авторизации)

## 2. Подход к тестированию

### 2.1 Типы тестов

| Тип        | Описание                | Приоритет |
|------------|-------------------------|-----------|
| Smoke      | Критический функционал  | P0        |
| Regression | Основной функционал     | P1        |
| UI/UX      | Валидация элементов     | P2        |

### 2.2 Паттерны

- **Page Object Model (POM)** — инкапсуляция логики страниц
- **Data-Driven Testing** — параметризация тестовых данных через Faker
- **Fixture-based** — управление состоянием через pytest fixtures

## 3. Окружение

### 3.1 Требования

- Python 3.9+
- Playwright 1.42+
- pytest 8.0+
- pytest-html (HTML-отчёты)
- allure-pytest (опционально)

### 3.2 Браузеры

- Chromium (headless/headed) — основной
- Firefox — дополнительный
- WebKit — дополнительный

### 3.3 CI/CD

- GitHub Actions
- Запуск smoke-тестов по push/PR
- Full regression — nightly

## 4. Критерии входа / выхода

### 4.1 Критерии входа

- Стабильная версия сайта доступна
- Тестовое окружение настроено
- Зависимости установлены

### 4.2 Критерии выхода

- Smoke-тесты: 100% pass
- Regression-тесты: ≥95% pass
- Критические баги задокументированы

## 5. Риски

| Риск                    | Вероятность | Митигация                              |
|-------------------------|-------------|----------------------------------------|
| Изменение селекторов    | Средняя     | CSS + XPath комбо, wait-стратегии      |
| CAPTCHA                 | Низкая      | Исключение из автоматизации            |
| Нестабильность сети     | Средняя     | Retry-механизм, настраиваемые таймауты |
| Рекламные баннеры       | Высокая     | Метод `remove_ads()` в BasePage        |

## 6. Метрики

- **Покрытие тестами:** ≥80% критического функционала
- **Время выполнения:** ≤10 минут (full suite)
- **Стабильность:** ≤5% flaky-тестов
