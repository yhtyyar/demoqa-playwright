## TC-001: TextBox — Валидация формы с корректными данными

| Поле           | Значение                                              |
|----------------|-------------------------------------------------------|
| **ID**         | TC-001                                                |
| **Приоритет**  | P0 (Smoke)                                            |
| **Тип**        | Functional                                            |
| **Предусловие**| Пользователь на странице `/text-box`                  |

### Шаги

1. Открыть страницу `https://demoqa.com/text-box`
2. Ввести "John Doe" в поле "Full Name"
3. Ввести "john@example.com" в поле "Email"
4. Ввести "123 Main St" в поле "Current Address"
5. Ввести "456 Oak Ave" в поле "Permanent Address"
6. Нажать кнопку "Submit"

### Ожидаемый результат

- Появляется блок с подтверждением
- Отображаются все введённые данные
- Текст в блоке соответствует введённым значениям
